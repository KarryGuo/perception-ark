一、基本信息

TRAE AI 创造力大赛是一场面向全民的 AI 创新实践赛事。无论你是否具备AI背景，依托 TRAE Work 与 TRAE IDE ，你都可以高效完成灵感梳理、方案设计、产品落地。

此外，大赛还将全程提供培训课程、导师辅导等多项运营资源支持，帮助参赛者跨过技术门槛，完成真正属于自己的创造。

赛事时间：2026年6月16日 00:00 – 2026年8月22日 23:59（北京时间）

参赛平台：TRAE 官方中文社区 TRAE AI 创造力大赛专区（报名、初赛、复赛均在社区完成，决赛为线下路演）

参赛资格：面向所有人开放（未成年人须在监护人同意下参与），初赛仅限个人参赛

开发工具：全程使用 TRAE Work 或 TRAE IDE （国际版/中国版均可）

参赛作品: 作品可以从0到1创作或在参赛期间有明显版本更新即可

赛事须知：请确保你注册 TRAE 中国版 与 TRAE 官方中文社区使用的是同一手机号，并在整个赛程中使用同一个社区账号参赛，否则可能影响资格校验和奖励发放（建议参赛过程中不更换社区昵称）。

二、赛程及赛道

2.1 赛程

本赛事所有时间均以北京时间为准。整体分为报名、初赛、复赛及决赛四个阶段。报名为提交创意形式，初赛需要提交demo，复赛提交完整作品，决赛为现场路演。

2.2 赛道

  • 本次大赛设有4个通用赛道和一个附加赛题；每个参赛选手根据自己的作品方向，选择4 个通用赛道之一进行提报，同时，参赛者还可根据作品情况，选择是否叠加提报附加赛题。
    • 如选择附加赛题参赛并在决赛中获奖，也会同步获得通用赛道奖励，奖励可叠加。

三、赛程详解

3.1 报名及初赛（2026年6月16日 - 7月15日）

  • 报名与初赛在同一时间段内同步进行（2026.06.16 – 07.15），仅支持个人参赛。在 TRAE 官方中文社区大赛 报名专区 发布"创意提案"帖，并添加相应赛道标签完成报名；报名通过后在 初赛专区 发布"Demo 作品"帖参加初赛。
    • 你可以将创意想法告诉 TRAE Work ，3到5分钟快速转化为完整的创意提案（HTML格式），并完成报名。TRAE Work 是 TRAE 旗下面向更广泛工作场景的AI产品。你可以通过其中的 work 和 code 模式高效完成内容创作、方案撰写、应用生成等任务。
    • 同时，你也可以借助 TRAE Work 或 TRAE IDE 将创意真正落地，构建能交互、可体验的 Demo，并提交初赛参赛作品。TRAE IDE 是一款深度融合 AI 能力的开发工具，提供从代码编写、项目理解、调试运行到变更管理的完整开发体验。你可以像使用传统 IDE 一样掌控每一步，也可以把复杂任务交给 AI 智能体规划和执行。

  • 初赛设专业评审通道（300 席）与抖音人气通道（50 席）两条独立晋级通道。
    • 专业评审通道：仅取你同一账号下综合得分最高的 1 个作品晋级；
    • 抖音人气通道：仅取你同一账号下人气分最高的 1 个作品晋级；
    • 若你的同一作品同时通过两条通道，仅占用 1 个晋级名额、不重复晋级也不顺延补位（因此实际进入复赛的作品总数可能少于 350 个）。完整规则详见下方《报名与初赛详细说明》。

3.2 复赛（2026年7月21日 - 8月9日）

复赛阶段，你需要在初赛 Demo 的基础上继续完善，交付一个具备完整用户路径和核心能力的正式产品。专业评审团将综合评分，择优选出 20 个作品晋级决赛。

你可以通过 TRAE Work 的 Code 模式或 TRAE IDE，在初赛 Demo 基础上持续开发与迭代，完善核心功能与产品体验，完成复赛作品交付。TRAE Work 的 Code 模式面向习惯于智能体主导开发的开发工程师，聚焦于编码、调试、代码库管理和 Git 工作流。

复赛的详细规则（提交要求、评审标准等）将随复赛阶段开启后另行公布，敬请关注大赛官网及社区公告。

3.3 决赛（2026年8月15日 - 8月22日）

决赛为线下路演形式。进入决赛后，你需要完成作品展示、项目讲解和现场答辩。决赛阶段，TRAE 赛事运营团队将 1V1 辅助参赛者完赛。

决赛的详细规则（路演流程、材料要求、评审标准等）将随决赛阶段开启后另行公布，敬请关注大赛官网及社区公告。

3.4 参赛作品通用要求

  • 创作工具：作品需全部使用 TRAE Work 或者 TRAE IDE 进行创作（国际版/中国版均可），不允许使用第三方工具，需提供能证明创作过程真实性的材料（如 AI 对话截图、任务历史、关键任务 Session ID、阶段成果截图等）。提交这些材料，即视为同意主办方仅为赛事审核、复核、评审及争议处理之目的，在必要范围内查看对应内容。
  • 功能可用：参赛作品原则上应包含可运行的体验链接（或者HTML格式文件）；硬件交互赛道可提交演示视频、录屏材料或其他可验证展示方式替代在线体验链接。
  • 原创性要求：参赛者应保证其提交的作品、演示内容、文案说明、页面素材、代码实现、设计文件及其他相关材料为本人或本团队原创。主办方有权在赛事任一阶段要求参赛者补充提交作品权属证明、创作过程说明或其他必要证明材料。参赛作品的全部或组成部分不得在其他赛事中获奖，且不得在公开平台以参赛成品形态进行公开展示。
