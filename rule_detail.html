3.2 晋级通道

初赛设有两条相互独立的晋级通道，合计最多 350 个复赛名额，其中：1） 专业评审通道：300 个晋级名额；2）抖音人气通道：50 个晋级名额。

  • 两个通道都必须在社区提交作品；
  • 两条通道名额均为固定名额，不因作品重叠而补位。 因此若有作品同时通过两个通道晋级，最终进入复赛的作品总数可能少于 350 个；
  • 同一选手的两个作品，一个通过专业评审、另一个获得 TOP 50 抖音人气榜：只保留专业评审晋级的作品，人气奖不补位；
  • 同一选手的两个作品都进入抖音人气榜 TOP 50：仅取人气更高的 1 个作品晋级，另一名额不顺延。

3.2.1 专业评审通道（300 席）

怎么参加： 提交完初赛帖，会由专业评审团按评审维度（详见4.2部分）打分，综合得分 TOP 300 晋级复赛。

基本要求：

  • 初赛 Demo 应与报名提交的创意方向一致；
  • 作品必须基于 TRAE IDE 或 TRAE Work 完成；
  • 需提供可体验地址（建议HTML格式），硬件交互赛道可提供演示视频；
  • 作品需能清晰展示核心功能和目标场景，而非仅停留于概念描述；
  • 参赛帖结构完整、内容清晰、便于评审。

  • 怎么参加： 在初赛专区提交 Demo 作品后，在抖音发布该作品的图文/视频，并带话题 #vibecoding大赏 #traeai创造力大赛 ，即视为参与「抖音人气」通道。

    • 【征集时间】：初赛期 2026.06.16 – 2026.07.15 23:59；
    • 【活动会场】：抖音搜索「vibecoding大赏」直达会场，可观摩学习优质作品
    • 【参与方式】：
      • 带话题 #vibecoding大赏 #TRAEAI创造力大赛 并 @TRAE.ai @抖音科技

维度

权重

说明

创新性

30%

30%

硬件交互赛道评估硬件与软件系统的协同能力

  1. 交互流畅： 硬件与软件数据传输稳定，响应及时，TRAE 参与后的调试与反馈链路顺畅
  2. 体验融合： 硬件功能与软件能力深度融合，共同提供完整的服务体验

4.2.2 抖音人气评审：四个维度计算

  • 人气分计算规则：

    人气分 = 点赞数 + 评论数 × 2 + 收藏数 + 转发数（点赞=基础认可度；评论=互动深度，含金量更高故 ×2；收藏=长期价值；转发=二次传播）

    • 最低门槛：单条内容点赞数 ≥ 500 方可进入人气榜计分；
    • 数据口径：同一作品可发多条，仅取数据最高的一条计分（不累加）；统计截止 2026年7月15日 23:59:59，以官方后台抓取的快照为准；
    • 复核：公布结果前对 TOP 100 候选视频进行数据复核，复核期 3 个工作日；
    • 同分规则：依次按 评论数 → 转发数 → 收藏数 优先；仍无法区分的由主办方结合内容质量、参赛规范及合规情况综合判定。
  • 刷量与作弊处理：
    • 主办方将联合抖音平台核查真实性，出现刷赞/刷评论/刷收藏/刷转发、同 IP 或设备异常集中互动、水评刷屏、有偿买量、内容与作品不符或搬运他人作品等情形的，直接取消人气奖资格、名次顺延；情节严重者取消全部参赛资格并追回已发奖励。

六、报名 & 初赛常见问题（FAQ）

Q：我是TRAE 国际版用户可以报名参赛吗？

A：当然可以。但是报名成功奖励只会发放中国版优速通月卡。

Q：我在社区成功发帖算报名成功了吗？

A：社区发帖不代表报名成功哦，官方每个工作日会对报名帖进行审核，审核通过后会进行通知。

Q：可以同时报名多个赛道吗？

A：可以报名多个赛道，也可以一个赛道报名多个创意。但每一个创意需要提交一个报名帖，且报名通过奖励只发放一次。

Q：多个创意都通过了报名，初赛能都提交吗？

A：可以提交多个对应的 Demo 作品；但晋级复赛评选时仅取你同账号下得分最高的 1 个作品。

Q：如果自己多个创意都通过了报名，怎么查询？

A：可以通过查询，通过名单按工作日更新，含社区昵称、报名帖标题、报名赛道、报名帖链接，可检索本人报名帖通过状态，报名未通过不再另行通知。

Q：如果在初赛专区发帖，但没报名通过可以吗？

A：不可以。初赛作品有效的前提是报名审核已通过。如果你只在初赛专区发了 Demo 但报名最终未通过，该 Demo 不会进入初赛评审。建议先确保报名帖通过，再提交 Demo帖，可以提前打磨。

Q：为什么我收到了报名通过通知却没有发放速通奖励？

A：报名成功后需要有7月15日（含）前登录大赛官网领取奖励的操作，领取确认后主办方才会发放速通奖励，请务必在官网确认是否已完成领取。当天完成报名的，奖励将于次日发放。

以下两种情况会导致领取失败：

① 已持有同类速通权益：若你已是 速通 Pro / 速通 Pro+ / 速通 Ultra / 优速通 Express 中的任一种，速通 Pro 奖励将自动发放失败，改由运营同学在 3 个工作日内补发等值奖励（价值 ¥99、100 次、有效期 31 天的速通权益）；

② 被风控识别为异常用户：即使收到报名成功通知，若被主办方风控系统判定为异常用户，仍会领取失败、不予发放。

Q：为什么强调"TRAE中国版和社区注册要保证同一手机号、全程使用社区同一账号"？

A：本次报名没有收集手机号等表单信息，社区账号和TRAE UID一一对应。如果注册 TRAE 中国版和社区用了不同手机号，或中途更换账号 / 昵称，系统可能无法把你的作品和奖励对应起来，导致资格校验失败或奖励无法发放，请务必在整个赛程中保持一致。

Q：报名审核未通过还可以修改报名帖吗？

A：不建议。建议重新在社区发帖提交创意，官方只会在工作日审核前一天的报名帖，如果是没有通过报名的旧帖子，编辑修改不会重新进入审核。

Q：一个初赛作品同时入围两个晋级通道，名额会浪费吗？

A：两个通道名额固定、互不补位。同一选手两作品分别从两通道晋级时，只保留专业评审晋级作品；因此实际进入复赛的作品数可能少于 350，这是规则设计，名额并未被浪费。

Q：想参与抖音人气榜晋级通道，必须先在社区发 Demo 帖吗？

A：必须。抖音人气榜是初赛的补充晋级通道，不替代社区报名、作品提交与资格审核。未在社区提交合规 Demo 的，即使抖音数据进入 TOP 50 也将取消资格、名次顺延给下一个抖音人气作品。

Q：怎么知道自己的抖音人气榜排名？

A：人气分按"点赞 + 评论 ×2 + 收藏 + 转发"计算，以官方后台 7 月 15 日 23:59:59 抓取的快照为准。进入 TOP 100 的选手，官方会通过抖音私信收集校验信息并复核，最终确认 TOP 50 榜单；结果将于 7 月 21–23 日在社区、社群、短信及官网公示，请留意 TRAE 官方抖音私信与官方公示。

Q：参赛作品必须是从0到1创建的吗？

A：作品可以是参赛期间从 0 到 1 全新创作的，也可以是已有作品在参赛期间完成实质性版本迭代的。无论哪种形式，相关开发工作均须使用 TRAE IDE 或 TRAE Work 完成，并能提供可证明开发过程真实性的材料 (如关键任务 Session ID、AI 对话记录、阶段成果截图等)。

所谓 "实质性版本迭代", 是指在核心功能、关键能力或主要用户体验上带来可感知的提升或扩展 (例如新增核心功能模块、重构关键流程、显著优化核心体验等), 而非仅做按钮文案、颜色样式、版本号等无实质影响的细微改动。主办方有权对更新的实质性进行核验，对不满足要求的作品不予评审。

Q：初赛要交「有交互、可体验的 Demo」，需要自己部署上线吗？

A：可以部署也可以不部署，别被「可运行」吓到～你可以借助 TRAE Work 或 TRAE IDE 把创意真正落地，构建一个可运行、可体验的 Demo，并提交初赛参赛作品。

评审的标准是能正常体验你的核心功能、理解 Demo 的核心价值即可达标，无需做成正式上线产品。你可以根据自身情况自由选择提交形式 ：

1、部署随时可公开访问的体验链接

2、交互式可体验的HTML格式文件，请使用Zip格式打包上传到社区

硬件交互赛道：如不便提供在线体验链接，可使用演示视频替代（请先将视频上传至 Bilibili 等第三方平台，再在帖中附上可公开访问的分享链接）。

Q：一个人最多可以获得几个奖项？

A：同一阶段的"参与类"奖励（如报名成功奖、初赛参与奖）每位选手仅发放一次，不因提交多个作品而重复发放；

决赛奖金部分，主奖项与专项奖可叠加，单个作品最高可得 35 万元现金；

阶段奖励与决赛奖金不冲突，你可以在拿到 Pro 月卡 / 专属礼包 / Pro+ 月卡等阶段奖励的同时，再获得对应决赛奖金。具体以最终公示与发放说明为准。

Q：若对晋级结果有异议，怎么反馈？

A：如对报名 / 初赛评审结果有异议，可在公示期内通过官方邮箱 feedback@mail.trae.cn 提交申诉，并附上你的社区账号、作品链接及具体问题说明。官方将在核实后给予回复，最终判定以主办方综合评审为准。
