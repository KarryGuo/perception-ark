设计理念

感知方舟采用眼镜形态——眼镜是人类最自然的"增强感知"载体， 摄像头自然位于视线前方，麦克风贴近耳侧，骨传导模块贴合太阳穴。 佩戴者不需要学习任何新交互，戴上眼镜即获得AI感知能力。 外观设计与普通眼镜无异，避免"残障标签化"。

01 / Problem

黑暗中的一千七百万人

中国有超过 1700万 视障人群。他们看不见红绿灯、认不出对面走来的是谁、读不了药盒上的说明书。 导盲犬全国不足5万只，覆盖率不到 0.3%。 而 AI 技术的爆发，让一种全新的可能浮出水面——不是多养几万只导盲犬，而是打造一副永不疲倦的AI智能眼镜。

PAIN 01

出行安全隐患

无法感知台阶、水坑、来车方向，跌倒和交通事故风险极高。路口无法判断红绿灯状态。

PAIN 02

信息获取壁垒

路牌、菜单、药盒、价签——生活中无处不在的文字，对视障者是完全不可见的屏障。

PAIN 03

社交孤立困境

无法识别对面走来的是谁，错过挥手、点头等社交信号，长期导致社交退缩与心理封闭。

PAIN 04

紧急情况无助

跌倒后无法起身更无法求助，突发身体不适无法拨打急救电话，黄金救援时间白白流逝。

02 / Scenario

视障者的一天

感知方舟不是一个功能清单，而是一个陪伴视障者从早到晚的全天候感知伙伴。 以下场景基于对 5 位视障用户（全盲3人、低视力2人）的深度访谈提炼， 覆盖出行、就餐、社交、紧急等高频生活节点——每一个时间节点，背后都有具体的AI智能体在工作。

07:00 · 早晨出门

场景感知 Agent 播报环境状况

"早安。今天多云，气温24度。门口路面干燥，左前方3米处有一辆共享单车，注意避让。电梯已到达6层。"

AGENT 01 · 场景感知
以前出门前，我要用手杖在门口探半天，不知道外面是晴是雨、有没有障碍物。现在戴上眼镜，它在我耳边说了一句，我就知道今天穿什么、往哪走。黑暗里终于有了第一缕光。
09:00 · 公交通勤

导航引导 Agent 精确引导到站上车

"直行15步到达公交站。326路公交车即将到站，请准备上车。上车后第二排靠窗有空位，向右转两步即可落座。"

AGENT 02 · 导航引导
同样是过这个路口，以前我站着听车流声判断方向，站了30秒没敢迈步。现在它说"绿灯，直行12步过马路，右侧无车"——我第一次走得这么快。不用再站在路口像根木头一样发呆。
12:00 · 午餐点餐

社交辅助 Agent OCR 读取菜单

"菜单第一页：红烧排骨饭28元，宫保鸡丁饭22元。第二页有今日特价：番茄牛腩面18元。您上次点过宫保鸡丁，要再来一份吗？"

AGENT 04 · 社交辅助
进餐厅以前是我最怕的事。看不了菜单，只能问服务员念，每次都觉得欠了别人一个人情。现在我自己就能"看"菜单，还能比较价格。终于不用再因为看不见而处处求人。
15:00 · 突发危险

安全预警 Agent 紧急打断所有输出

"注意！右侧有电动车快速接近，距离5米，请立即向左避让！" —— 骨传导耳机以最高音量播报，同时镜腿高频震动。其他所有Agent输出被即时挂起。

AGENT 03 · 安全预警 · 最高优先级

04 / Multi-Agent

五大智能体：各司其职

中央协调 Agent · Orchestrator

统一调度五个专业Agent · 任务分配 · 优先级仲裁 · 冲突消解 · 上下文管理

⚠ 安全预警 Agent 拥有最高优先级，可随时打断其他所有Agent的输出

AGENT 01

场景感知 Agent

持续运行的环境描述引擎，每3秒输出一次周围环境摘要，帮助视障者在脑海中构建实时"画面"。

  • 实时物体识别与空间定位
  • 距离估算（"前方3米有台阶下行"）
  • 环境语义描述（"左侧是便利店入口"）
  • 场景切换检测（室内→室外、街道→商场）
AGENT 02

导航引导 Agent

根据用户语音告知的目的地，实时规划步行路径，以方向+步数的方式精确引导。

  • 语音目的地输入与路径规划
  • 实时避障引导（"向右转30度"）
  • 步数级精确导航（"直行5步后左转"）
  • 公共交通辅助（公交到站提醒）
AGENT 03 · 最高优先级

安全预警 Agent

7×24不间断运行的危险检测引擎，发现威胁立即打断所有其他输出，以最高音量紧急播报。

  • 车辆靠近预警（方向+距离+速度）
  • 跌倒检测与自动SOS呼救
  • 高空坠物风险提示
  • 地面异常检测（水坑、湿滑、台阶边缘）
AGENT 04

社交辅助 Agent

按需激活的信息读取与社交辅助引擎，帮助视障者获取文字信息、识别社交场景。

  • OCR文字识别（路牌、菜单、药盒、价签）
  • 面孔识别（"前方走来的是同事小王"）
  • 货币面额识别
  • 颜色与衣物搭配辅助
AGENT 05 · P3

环境记忆 Agent

这是PerceptionArk区别于普通智能眼镜的核心。它持续学习用户的常用路线、熟悉面孔、生活节奏和偏好习惯，让眼镜从"陌生工具"逐渐变成"贴身伙伴"。用户走得越多，眼镜越懂路；见的人越多，眼镜越懂谁重要；用得越久，越像一位老朋友。

  • 路线记忆 · 常走路径自动优化
  • 面孔库 · 熟人优先播报
  • 习惯学习 · 记住每日作息
  • 场景偏好 · 学习播报偏好
  • 离线缓存 · 断网也能用

TECH STACK

向量数据库：本地 SQLite-VSS 存储路线轨迹与面孔特征向量，余弦相似度匹配，无需联网
增量学习：用户行为日志以时间窗口加权，新数据权重高，遗忘曲线衰减旧数据，避免全量重训
习惯挖掘：基于时序模式（Time2Graph）提取每日作息规律，异常检测触发提醒
隐私边界：所有记忆数据仅存于眼镜端本地，不云端同步，恢复出厂设置即清除

→ 映射到 Orchestrator + 5 Agents
🔧

工具调用 (Tool Use)

TRAE Capability → 各Agent专业能力

为每个Agent配置TRAE工具链：场景感知Agent调用视觉理解API；导航Agent调用地图SDK和路径规划工具；安全Agent调用物体检测+测距工具；社交Agent调用OCR和人脸识别工具；环境记忆Agent调用本地向量库与习惯学习模型。TRAE统一管理工具注册与调用。

→ 映射到 Agent 工具链配置
🧠

上下文管理 (Context Management)

TRAE Capability → 跨Agent状态共享

利用TRAE的上下文管理能力，维护一份共享环境状态：当前GPS位置、场景类型（室内/室外/路口）、最近危险事件等。各Agent读取共享上下文做出更精准判断，避免重复推理。

→ 映射到 Shared Context Layer
⚡

流式输出 (Streaming Output)

TRAE Capability → 实时语音播报

利用TRAE的流式响应能力，Agent的推理结果以流式方式传输到语音合成模块，实现"边推理边播报"。场景描述从原来的3秒等待缩短至首字输出<500ms（云端4G网络条件下），端侧安全预警延迟<200ms（NPU本地推理），大幅降低感知延迟。

→ 映射到 语音合成流式通道
🎯

意图识别 (Intent Recognition)

TRAE Capability → 语音指令理解

用户说"带我去超市"时，TRAE的意图识别能力解析目的地实体，触发导航Agent；说"读一下这个"时，触发社交Agent的OCR。自然语言指令无需固定话术，降低视障者的学习成本。

→ 映射到 语音交互入口
🔄

多轮对话 (Multi-turn Dialogue)

TRAE Capability → 上下文连续交互

"前方是什么？""是一家药店。""帮我读一下招牌。"——利用TRAE多轮对话能力，视障者可以基于Agent上一轮播报进行追问，系统保持对话上下文，实现自然连续的感知交互。

→ 映射到 对话管理模块

07 / Latency & Edge

延迟优化与边缘降级

视障感知是生死攸关的实时场景——0.5秒的延迟可能意味着一辆电动车已经撞上。 感知方舟从架构层面设计了端云协同和三级降级策略，确保任何网络条件下都不失能。

<200ms 安全预警延迟（端侧NPU）
<500ms 场景播报首字输出（云端流式）
<1.5s OCR识别完整返回
30fps 视频流处理帧率
LEVEL 1 · 完整模式

云端大模型 + 全Agent协作

网络畅通时，五Agent全功能运行。视觉理解、OCR、人脸识别等重计算在云端完成，眼镜端仅负责传感器采集和语音输出。延迟最优、功能最全。

LEVEL 2 · 边缘降级

端侧轻量模型 + 核心Agent保活

网络不稳定时，自动切换到眼镜端轻量模型。安全预警和场景感知由端侧NPU实时运行（YOLO目标检测+距离估算），导航和社交Agent降级为缓存模式。安全能力绝不中断。

LEVEL 3 · 离线保命

纯本地安全守护 + 跌倒SOS

完全无网络时，系统进入纯离线保命模式。IMU跌倒检测+本地SOS呼救+最后位置缓存。一旦网络恢复，自动同步离线期间的告警日志到家属端。

08 / Privacy

隐私与安全：底线设计

摄像头持续拍摄 + 人脸识别 = 极高隐私风险。 感知方舟从第一天起就将隐私保护作为架构级约束，而非事后补丁。

📱

边缘优先处理

视频帧在眼镜端NPU上完成目标检测和特征提取，仅将结构化描述（"前方3米有台阶"）传输到云端。原始视频流不上传，从物理层面杜绝视频泄露。

🗑️

零留存策略

所有感知数据在推理完成后立即销毁，云端不存储任何环境快照。仅跌倒SOS事件保留脱敏日志（时间+位置），用于家属端历史查询。

🔐

人脸识别授权制

面孔识别功能需用户主动开启，且仅在本地特征库中匹配用户预先登记的熟人。不接入任何公共人脸数据库，不进行陌生人身份推测。

📵

物理遮挡开关

眼镜配有物理摄像头滑盖——用户可随时手动遮挡摄像头，系统自动进入纯IMU+麦克风模式。软件隐私开关之外，提供硬件级的信任保障。
